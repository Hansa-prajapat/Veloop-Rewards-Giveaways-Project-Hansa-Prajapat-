# VELOOP Rewards & Giveaways — Premium Icon UI

A polished React + Vite frontend demo for a Watch & Earn rewards experience.

## Included
- Premium dark blue/purple glass UI
- Lucide SVG icons instead of emoji-based UI symbols
- Animated active navigation underline with glow/slide effect
- Watch & Earn flow with countdown and reward completion
- 6 demo ads with distinct visual treatments
- Daily progress, earnings and activity
- Weekly leaderboard and gift rewards
- Separate Profile page
- Winner Gift Entry form and saved demo status
- How It Works and Eligibility & Safety pages
- Responsive layout for desktop/tablet/mobile
- LocalStorage demo persistence

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Important
This is a frontend demonstration. VE points, leaderboard positions and gift entries are sample/demo data until a real backend, verified reward provider, terms and fulfilment process are connected.
